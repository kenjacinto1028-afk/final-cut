# Final Cut v13.1 — How It Changes Gameplay

1. **Studio economics:** High-end films have a little more box-office reach and can benefit from a wider release, but remain expensive. Mature-studio revenue-linked overhead/taxes are less punishing; fixed overhead still scales with size. Carefully budget for large productions.
2. **Indie opportunity:** Well-liked microbudget and low-budget movies benefit from word of mouth. Critically strong profitable features under the low-budget threshold receive a bounded extra legacy score, not fake gross or awards.
3. **More meaningful awards:** There are now stricter merit floors and studio/film win limits, preventing extremely successful studios from winning every category or every festival without limiting nominations or festival selections. Rivals follow the same rules.
4. **Reputation requires attention:** Current Buzz dissipates faster and weaker films can more noticeably hurt it. Permanent historical fame and Lifetime Legacy are preserved; new acclaimed releases remain rewarding.
5. **Rival histories and world championships:** World rankings remain based on actual scored films, even when a rival wins. An old QA assertion falsely expected the player to be first and is now corrected.
6. **Custom posters:** No gameplay changes to IndexedDB poster storage. Browser-level mocks and backup workflows pass; real-origin tests still require a browser where the deployed URL is accessible.

**Compatibility:** Existing saved v13 games and prior supported save migrations remain available. Engine save version is intentionally unchanged for this balance-only release.
